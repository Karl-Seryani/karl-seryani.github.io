# Karl Seryani

Personal portfolio with security research, selected projects, and experience.

[View the portfolio](https://karl-seryani.github.io/)

## Updating the site

Edit `index.html` for the homepage and `research/<article>/index.html` for writeups. Shared styles and interactions are in `style.css` and `site.js`.

GitHub Pages publishes the root of the `main` branch. No build step or dependencies are required.
