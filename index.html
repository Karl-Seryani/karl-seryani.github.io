Multi-agent security testing

AI security tooling

April 2026 to present

A multi-agent workflow that finds cloud vulnerabilities and tries to disprove them.

The workflow maps cloud APIs, runs tests, and challenges every positive result. It turned more than 1,500 test ideas into 11 Google Cloud vulnerability reports. Google triaged 3 reports and accepted 1.

A critic agent must fail to disprove each finding before the finding goes into a report. The researcher, hunter, and critic roles each run on a separate AI model.

How it works

A SQLite database stores each finding and test idea under a unique ID. The agents ask the database for only the data they need. This replaced a large Markdown file, so each run uses fewer tokens and costs less.

A Python request tool checks every request against a 220-rule host allowlist. It blocks out-of-scope and duplicate tests and saves more than 3,100 experiments as proof that anyone can replay.

Built with Python, SQLite, and Claude Code.
