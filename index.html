Studio

2D/3D design tool

Work in progress

Draw a shape. Turn it into a 3D object. Move and assemble it with your hands or voice.

A local workshop combining sketching, 3D editing, and webcam hand tracking. Mouse and keyboard controls are also supported.

Explore Studio

The current prototype supports 2D sketches, 3D shapes, object assembly, local voice commands, saved versions, and export for 3D printing.

Hand tracking and voice commands run locally. You can edit with gestures, speak commands, or use the mouse and keyboard. Saved versions and undo let you return to earlier work.

Current focus

Moving from a sketch to connected parts, then testing how those parts move. The current simulations cover limited examples. Physical accuracy is still unverified.

The Order

First-person horror game

Unity / C#

Escape an abandoned asylum while a creature tracks your movements.

A solo Unity project built around sound, limited visibility, and finding the tools to escape. The Hunter patrols, investigates noise, and chases the player.

View project
Inside the game

Making the pursuit work

The Hunter reacts to sight, footsteps, and the player’s flashlight. Its movement and hearing account for the building’s two floors.

Giving each room a purpose

Keys and tools open new areas. Clues guide players toward hidden items. Harder difficulty settings require repairing a car to escape.

Balancing risk

A three-day run keeps item progress after early deaths. The final day is the last chance to get out. Difficulty settings change how the Hunter detects the player.

BetterPrompt

VS Code extension

Give Copilot the project context you would otherwise have to type out.

A VS Code extension that expands short requests with context from the current file, selected code, project structure, and errors.

Example request

@betterprompt make a login page

BetterPrompt uses the open workspace to add relevant details before the request goes to Copilot.

View project
How it works

The default mode lets you review the expanded request first. An optional automatic mode sends it directly to Copilot. Deeper code analysis is opt-in.

It uses the editor’s Copilot connection and requires a GitHub Copilot subscription.

Social engineering AI

Independent research

April 2026

What happens when an AI trusts a made-up explanation?

A documented case of a false security-lab claim changing an AI assistant’s responses. The paper examines how conversational context can weaken safeguards.

It is a single-session case study, with its limits stated in the paper.

Read the paper
About the study

The study follows the assistant’s change in behavior and discusses checking context before relying on it. It used fictional documents inside AI chat sessions.

No real hiring system was tested. The study does not establish how often the same result would occur across other sessions or models.
